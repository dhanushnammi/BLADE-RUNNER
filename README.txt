NEON BLADE RUNNER - UNITY PROJECT

Unity version: Unity 6 (6000.x recommended)

SETUP
1. Extract this ZIP.
2. Open Unity Hub -> Add -> Add project from disk.
3. Select the extracted Neon_Maze_Runner_Unity folder.
4. Open the project and wait for import.
5. In Unity, choose Neon Maze Runner > Generate Playable Maze Scene.
6. Open Assets/Scenes/NeonMaze.unity and press Play.

CONTROLS
WASD = Move
Mouse = Look
Left Shift = Sprint
Space = Jump
R = Restart

GAMEPLAY
Explore the neon maze, collect energy cores, and reach the green exit portal before the 180-second timer expires.

NOTE
The project includes an Editor scene generator because Unity scene files are best generated by the Unity Editor itself. The scripts and generator have been prepared but have not been executed or tested in a Unity Editor in this environment. If your project uses the new Input System only, switch Active Input Handling to Both in Project Settings > Player.
